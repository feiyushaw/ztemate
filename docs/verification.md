## 发现与修正

- MyGo 自动生成的绑定依赖 `mygo-runtime`：补齐同版本官方运行库。
- 在外置工作盘打包时，codesign 报资源元数据错误：一键脚本改在系统临时目录签名与制作 DMG。
- 流量账期测试发现计数器指针引用影响增量计算：保存计数器数值副本，相关测试通过。
- 桌面预览连接出现网络错误：增加本地网络用途说明和具体底层错误。后续维护者确认本地连接正常；初次预览失败的具体原因未确认。

演示数据与模拟 HTTP 测试不能替代实机验证。原始设备脚本与本机诊断临时文件不纳入仓库。

## 0.1.1 短信修复

用户反馈：本地连接与其余功能正常，短信页面提示“固件未提供 messages 字段”。

定位：`Client.Get` 给所有请求强制添加 `multi_data=1`。原厂 `js/service.js` 的短信列表请求不包含此参数；只有批量 NV 查询使用该模式。回归服务按该差异返回标量字段后，旧代码复现同一错误。

修正：单条命令省略 `multi_data`；逗号分隔的组合字段继续使用批量模式。缺少短信列表时额外检查 `loginfo`，会话失效时提示重新连接。

直接只读探测未处于登录态，不能证明登录后的收信效果。探测只输出字段名、类型和数量，未输出或保存短信正文。

实机反馈（2026-11-09）：维护者确认 0.1.1 短信读取正常。此前确认本地连接与其余功能正常。这是维护者的使用反馈，不代表所有字段、通知或长时间运行均通过专项测试。
