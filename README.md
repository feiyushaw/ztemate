ZTEMate 使用 **MyGo + Go + Vue 3 + TypeScript + Tailwind CSS** 构建。网络请求与短信同步由 Go 后台负责，界面使用 macOS 系统 WebView。关闭主窗口后，应用继续在菜单栏运行。

当前版本为 **0.1.1 开发预览版**，以 MC888S 为首个适配目标。项目独立维护，与中兴及运营商没有官方关联。

## 功能

| 功能 | 说明 |
| --- | --- |
| 菜单栏弹窗 | 查看连接状态、实时速率和最近验证码；点击复制验证码 |
| 网络总览 | 网络制式、5G 信号指标、整个路由器的上下行速率和最近 60 秒曲线 |
| 短信中心 | 按号码聚合会话、搜索正文、提取验证码、SQLite 本地归档 |
| 接入设备 | 展示固件提供的无线与有线设备信息 |
| 本地流量计划 | 套餐额度、已用量校准、剩余量、账期清零、阈值提醒，支持流量或时长套餐 |
| 流量计划导入 | 读取路由器套餐配置到表单，保存为本地计划 |
| 偏好设置 | 深浅色与系统外观、开机启动、新短信通知 |
| 演示模式 | 不连接路由器即可查看界面；演示短信不写入数据库 |

**当前不提供**短信发送、远端删除、标记已读、锁频、设备限速或自动断网。流量计划只保存在本机，不修改路由器配置。

## 从源码构建

### 环境

- macOS：制作 `.app` 与 `.dmg`。
- Go **1.27.3**：由锁定的 MyGo **v0.8.3** 要求。较早的 Go 在 `GOTOOLCHAIN=auto` 时可以自动下载所需工具链。
- [Bun](https://bun.sh/)：测试环境为 1.4.3。
- Node.js **22.12 或更高版本**：运行前端工具；测试环境为 24.11.1。

首次构建需要联网下载 Go 工具链与依赖。

### Apple Silicon

```bash
git clone https://github.com/feiyushaw/ztemate.git
cd ztemate
bun install --frozen-lockfile
bun run build:mac
```

安装包输出到：

```text
build/darwin-arm64/ztemate-0.1.1-arm64.dmg
```

打开 DMG，将 `ZTEMate.app` 拖入“应用程序”。更新时，先从菜单栏退出旧版本，再打开新版本。

### Intel 与 Universal

以下入口尚未经相应架构验证：

```bash
bash scripts/build-mac.sh darwin/amd64
bun run build:universal
```

对应输出目录为 `build/darwin-amd64/` 和 `build/darwin-universal/`。

构建脚本在系统临时目录签名、制作 DMG，再复制回项目，避开部分外置文件系统附加的 Finder 元数据导致的签名错误。

默认采用 **ad-hoc 本地签名，未经 Apple 公证**。源码构建不等同于可供公众直接安装的公证发行包。正式分发需使用自己的 Developer ID 和公证配置；`MACOS_SIGNING_IDENTITY` 可指定签名身份。参考 [MyGo 分发文档](https://mygo.egoist.dev/docs/distribution)。

## 使用方法

1. 确认 Mac 可以打开路由器管理网页。
2. 打开 ZTEMate 的“设置”，填写实际管理地址，例如 `http://192.168.1.1`。
3. 输入管理密码，点击“连接并登录”。
4. 在“短信”中查看消息，或从菜单栏复制验证码。
5. 在“流量”中配置本地套餐，或读取路由器计划后保存到本机。

**示例地址不是统一默认网关。** 管理地址只填写协议、主机与可选端口，不包含 `/index.html` 或 `#traffic_alert`。

密码仅用于当前登录，不保存到数据库。重启应用后需手动重新连接。应用不自动重复登录；会话失效时，在设置中重新连接。若网页管理与应用的会话互相影响，可以暂时暂停监控。

关闭主窗口不会退出应用；从菜单栏右键菜单选择“退出”。

## 流量统计与提醒

- **读取路由器计划**：只读取套餐配置。
- **保存本地计划**：只写本机数据库，不改变路由器清零、套餐或断网设置。
- **已用量校准**：指定本地起始用量，后续累加路由器计数器的变化。
- **账期清零**：日期支持 1–31 日；不足指定日期的月份使用最后一天。
- **阈值提醒**：应用运行并成功采集数据时，每个账期首次达到阈值通知一次。

路由器计数器归零时，本地累计值继续保留。账期边界离线时，恢复采集的读数作为新基线，无法精确重建跨账期的离线用量。

流量计划按 1024 换算 MB/GB/TB，与测试固件的网页一致。速率按十进制 KB/s、MB/s 展示。统计覆盖整个路由器，不代表某台设备的独立流量，也不代替运营商账单。

## 隐私与本地数据

应用无需云端账户。应用直接访问用户指定的路由器，不主动上传短信或运行数据。主动点击“管理后台”时，会在系统浏览器打开对应地址。

本地数据库位置：

```text
~/Library/Application Support/ZTEMate/ztemate.db
```

数据库保存短信正文、连接地址、偏好和流量计划，不保存管理密码。文件权限为 `0600`，**数据库没有单独加密**，依赖用户账户和磁盘保护。本地归档仍占用磁盘空间，不承诺无限保存。

通知不展示短信正文或验证码。只有用户点击复制时，应用才写入剪贴板。首次系统通知与开机启动的行为取决于 macOS 权限和应用签名状态，尚未完成所有场景验证。

## 开发与检查

```bash
bun run dev          # MyGo 桌面开发模式
bun run dev:web      # 仅前端预览：http://127.0.0.1:5173
bun run typecheck
bun run build:web
go test ./...
go test -race ./internal/...
go vet ./...
```

浏览器预览不连接路由器，也不持久保存数据。点击“先体验一下”查看演示内容；`/?view=tray` 预览菜单栏布局。

项目结构：

```text
main.go                 MyGo 生命周期、窗口与菜单栏
internal/zte/           GoForm 登录、只读请求、短信解码
internal/app/           共享状态、轮询与流量统计
internal/store/         SQLite 归档与偏好存储
src/components/         通用界面组件
src/views/              总览、短信、流量、设备、设置与弹窗
scripts/build-mac.sh    macOS DMG 构建入口
```

协议测试使用模拟 HTTP 服务，不需要真实路由器或密码。测试覆盖查询模式、会话 Cookie、短信编码、分页重复、归档去重、远端 ID 复用、流量计数器重置与账期变化。

## 常见问题

**网络正常，但短信提示会话失效。** 部分网络指标在未登录时仍可读取。请在设置中重新连接，不能仅凭网络状态判断短信访问权限。

**短信响应格式不匹配。** 先确认使用 0.1.1 或更新版本。仍然失败时，请提交型号、网页版本和界面中的字段名提示，不要提交短信正文或会话 Cookie。

**刚打开的应用没有“流量”页面或新提示。** 菜单栏中的旧版本可能仍在运行。先退出旧版本，再打开新版本。

**缺少信号字段或设备列表。** 固件不一定暴露全部接口。请提交功能缺失报告，不要据此填写假读数。
